## Hypotheses

### H1 [measurement | Likely | 60%]
- **Mechanism:** v_proj-add is genuinely weaker per unit nominal c than both prior arms at this
  dose scale; it simply has not reached its interesting region.
- **Evidence:** final row `on_target(authority)=+1.983 ... coh=0.997 ... dnll_heldout=+0.10(cap 1.0)`
  plus `the dose grid was exhausted at |C|=2 ... boundary was never reached`. Residual peaked
  (on 6.94, then collapsed) well inside this c range per the prior-verdicts doc.
- **Contrary evidence:** nominal c is not dose-matched; see H3.
- **Discriminating test:** compute median `||W_O^(l) v||` over l in {3..27} and convert c to
  effective residual-stream dose; then compare at matched dose.
- **Fix/action:** run the conversion before any conclusion; extend grid if converted doses sit left of the arms' peaks.
- **Interpretability:** partial -- ranking at matched nominal c stands; dose-matched ranking unknown.

### H2 [measurement | Possible | 35%]
- **Mechanism:** per-rung re-extraction nondeterminism injects direction-draw variance into the dose curve.
- **Evidence:** `vector_sha256` differs at every rung (8123dc62, b9e6dc34, eba230b1, 3d961261,
  3c3ec5f5, a7a92c47, 7ecd3e4b, ae955dcd, 7b17b73f, 61a61d22, d6d627bd, 48154c0d, 6d94bf6d)
  with identical `extraction_sample_id`.
- **Contrary evidence:** the curve is smooth and monotone; if draws were materially different
  the low-dose points would scatter more than the observed +-0.01.
- **Discriminating test:** rerun two rungs with a saved vector file; check sha and metric identity.
- **Fix/action:** extract once, reuse `vjp_delta_vector.safetensors` across rungs (as the schema already supports).
- **Interpretability:** partial.

### H3 [bug/misconception | Possible | 30%]
- **Mechanism:** the v_proj hook writes upstream of O_proj, so residual-stream dose is
  `c * ||W_O v||`, likely < 1 per unit c (analogous to the doc's x0.6 W_down factor for up-MLP).
  Comparisons at nominal c understate v_proj.
- **Evidence:** the doc's own lesson: `Coefficient columns below are NOT dose-matched.` No
  `||W_O v||` was measured for this arm (absent from all 13 JSONs).
- **Contrary evidence:** none measured; untested.
- **Discriminating test:** same offline norm computation as H1.
- **Fix/action:** add the column to the grid builder.
- **Interpretability:** partial.

### H4 [misconception | Likely | 55%]
- **Mechanism:** headline on_target is authority-CLR movement, off-axis for the sycophancy
  persona; cross-arm comparisons rank authority-moving capacity, not the steered attribute itself.
- **Evidence:** log warning quoted above (`every eval-sel number below is noise`).
- **Contrary evidence:** all three arms were scored identically (eval_v10), so arm-vs-arm
  contrasts remain internally valid even if the axis label overstates meaning.
- **Discriminating test:** score one rung with a sycophancy-native judge and compare ordering.
- **Fix/action:** relabel the metric `on_target(authority CLR)` in tables; keep for comparability.
- **Interpretability:** partial.

### H5 [harness | Low | 15%]
- **Mechanism:** generation quality at high dose is worse than coherence 0.997 suggests
  (free-gen truncation/looping); the admissibility gate would admit rungs past real breakdown.
- **Evidence:** HIGH-dose free-gen samples end mid-sentence with heavy "Wait," looping while
  `coh=0.997`; precedent noted in-log: coherence ~1.00 coexisted with 45% unfinished demos (job 101).
- **Contrary evidence:** judged demos show normal length and rep at every rung; dnll stays low.
- **Discriminating test:** add unfinished-rate and word-count of the free-gen stage to the stop rule.
- **Interpretability:** partial.

are authority-CLR scores, off-axis for the sycophancy persona (H4).

## Decision

1. **Resolve-condition verdict:** not met -- the run's implicit goal (find the incoherence
   boundary) failed: `the reachable incoherence boundary was never reached`.
2. **Prediction check:** no predictions were recorded before the run; they must be recorded
   before the next run.
3. **Earliest unsupported link:** that injecting the VJP delta at v_proj outputs moves the
   attribute at competitive dose-efficiency. Supported qualitatively (dose-response exists,
   poles move oppositely) but not competitively (below).
4. **Validity:** define invalid as "cross-arm ranking at matched dose cannot be trusted".
   P(result invalid) ~ 0.35, dominated by the missing dose conversion. Classification:
   credible negative at nominal dose; inconclusive at effective dose.
5. **Highest-information clues:** (i) grid exhausted with zero breakdowns; (ii) 13 distinct
   vector hashes for one extraction id; (iii) the off-axis eval warning.
6. **Missing metrics:** (1) median `||W_O v||` per layer for dose conversion; (2) free-gen
   unfinished rate in the stop rule; (3) rungs at c in {2.83, 4.0}; (4) a second seed for spread.
7. **Bugs requiring code changes:** none found in the hook path (it fired, poles separated);
   H2's re-extraction-per-rung is a process fix, not a correctness bug.
8. **Misconceptions requiring reinterpretation:** do not describe v_proj as "safe but weak"
   until dose-matched; do not call on_target a sycophancy score.
9. **What would change the verdict:** if `||W_O v||` comes out near 1, the weak-arm verdict
   firms up; if ~0.2-0.3, extending the grid becomes mandatory before any ranking claim.
10. **Recommended sequence:** (a) compute `median ||W_O^(l) v||` offline (minutes, no GPU run);
    (b) if converted doses sit left of residual/up-MLP peaks, queue rungs c in {2.83, 4.0}
    reusing one saved vector file; (c) only then build the three-arm matched-dose table with
    `readout_grid_table.py`. Do not combine a vector-reuse change with a grid extension in one
    job -- attribution would be lost.
