## Learnings

- The pi process manager returned `ENOENT` for its own `/tmp/pi-processes-un0xDm` stdout path twice. Do not wait on it for this Modal job.
- `scripts/export.py --run` must append named new runs because regenerating all rows could alter the existing table.
- Artifact discovery must glob each named method file, because run directories contain non-artifact JSON.
- A direct `uv run scripts/judge.py` pueue command bypasses `justfile` dotenv loading. Queue named judging through `just judge --run ...` so the existing ignored project key is loaded.
- `modal app logs <app-id> --follow --timestamps` streams a detached Modal app. `just modal-follow <app-id>` is the project command.
- Transient judge HTTP failures require the same bounded backoff as connection failures; otherwise a final 429 falls through the retry loop and crashes the batch. The status handler must identify HTTP failures by `status_code`: a provider `InternalServerError(503)` did not enter the nominal OpenAI status-exception branch, while the generic status-coded branch passed a three-retry 503 test. Handle status-less `APITimeoutError` before generic `Exception`, or the generic handler re-raises it before the retry code can run.
